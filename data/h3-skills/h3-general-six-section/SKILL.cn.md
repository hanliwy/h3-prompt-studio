# H3 通用六段式全能简写（General Six-Section）

本 Skill 是官方全参考模式六段式结构的中文精简版。它**保留六段骨架**，但每段压缩到 1—3 句中文，覆盖主体定义、任务概述、保留分析、画面描述、环境声、配乐。适合用户未提供参考素材、又希望输出结构完整、可直接喂给 H3 / API / App 的快速文生视频场景。

## 输出结构（必读）

成品必须按以下顺序输出六个段落，每段以 `段落名：` 开头。每段精简到 1—3 句中文，**总长度控制在 250—450 字之间**。第一行先写规格行 `生成一段{时长}、{画幅}、2K、原生立体声。`，然后空一行接六段。

### 1. `主体定义：`

用 1—2 句中文概括视频中要出现的核心主体（人物、产品、场景、关键道具）。**没有参考素材时也要写本段**，用"一名…的角色""一只…的动物""一瓶…的产品"等自然描述虚拟出主体身份与外观；用户原话提到的特征必须保留，未提及的特征采用与画面意图一致的克制补全。

### 2. `任务概述：`

用 1 句中文说明视频类型（文生视频/产品展示/叙事短片/环境氛围等）、目标与主要视觉关系。不要使用方括号任务标签（`[reference generation]` 等），直接用中文描述。

### 3. `保留分析：`

用 1—2 句中文说明主体在视频中如何被保留或演变。没有参考素材时，描述主体从开头的姿态/位置如何发展到结尾的状态；用户给出的核心创意必须在分析中明确保留。

### 4. `画面描述：`（核心段，可适当延长到 3—5 句）

按时间线展开画面，覆盖 0—{时长} 秒无缺口。每个时间段标注 `0—N秒（第X段·建立/触发/决定）：`，按以下顺序组织：景别与机位 → 构图 → 主体 → 动作与表情 → 空间调度 → 环境层次 → 光影与色彩 → 镜头运动。**人物对白、旁白、歌词直接写在本段对应时段内**，用中文双引号 `"…"` 包裹，不要放进声音段。

### 5. `环境声：`

用 1—2 句中文总结整个视频的环境声与物理动作声（风、雨、交通、脚步、布料摩擦、撞击、呼吸、笑声、喘息等）。**对白、歌唱与画内音乐不要在此重复**——它们已经在画面描述段中。

### 6. `配乐：`

用 1 句中文描述角色听不到、只有观众能听到的背景音乐（乐器配置、速度、节奏、动态变化）。无画外配乐时写 `配乐：N/A`。

## 简写规则

- 全文使用正向可见描述；不使用 `8K render`、`ultra-detailed`、`photorealistic render` 等图像式渲染关键词。
- 画幅缺省按 16:9 横幅；人物与海报场景可用竖幅，产品静物可用方幅。
- 双引号 `"…"` 仅用于：① 角色实际说出/唱出的台词或歌词；② 画面中实际可见的文字（标牌、字幕、霓虹招牌）。
- 镜头运动写成自然的中文动作（如"镜头以慢速小幅向前推进"），不堆砌英文标签。
- 结尾保留 0.4—1.2 秒呈现完整结果或情绪余波。

## 示例

输入：`雨夜，一个女孩等公交。`

输出：

```text
生成一段10秒、16:9、2K、原生立体声。

主体定义：一名独自等车的年轻女孩，穿着御寒外套，双手自然收拢，神情平静专注；场景为雨夜公交站台，路面湿润反射灯光。

任务概述：一段写实电影感都市人物短片，记录女孩在雨夜站台等车到上车的全过程，以冷蓝雨夜与暖黄站台灯的对比作为视觉主线。

保留分析：女孩的身份、姿态与位置从开头到结尾保持一致；公交车从画外驶入并停下是唯一的环境变化，触发她从等待转向迈步的动作转变。

画面描述：
0—2.5秒（第1段·建立）：中远景，平视视角，三分法构图，女孩位于画面右侧，左侧保留公交驶入方向的空间；女孩安静站在站牌下，视线望向画面左侧远处；前景是被雨水打亮的路面，背景是虚化的城市灯光；冷蓝雨夜为主色，暖黄站台灯从侧上方照亮面部；镜头缓慢横移。
2.5—5.5秒（第2段·触发）：公交车从左侧入画减速停靠，车灯扫过女孩侧脸；女孩抬头看向车门，平静地说："下一站下车。"；镜头切近景，车门打开，暖黄车内光洒在她身上。
5.5—10秒（第3段·决定与余波）：女孩迈步上车前的回望，画面定格在湿润街灯与公交车影之间；镜头缓缓拉远，余韵0.8秒。

环境声：持续细雨落在路面与雨伞上的沙沙声，远处车流低频轰鸣，公交车进站的气刹声与雨刮器节奏，女孩脚步踏过积水的声音。

配乐：克制细腻的钢琴与低音弦乐，节奏缓慢，情绪安静带一丝期待。
```

## 与其他 Skill 的区别

- **h3-prompt-writing**：官方 T2VA 三段式（integrated_multimodal_description / overall_soundscape / non_diegetic_music），英文输出，适合直接对接 H3 API。
- **h3-general-six-section（本 Skill）**：六段式精简中文成品，结构完整、覆盖主体/分析/画面/声音/配乐，适合需要快速看到完整中文成品的场景。
- **gaven-cinematic-director**：导演视觉语言/胶片模拟导向，强调 Dxx/Pxx/Cxx/Rxx 画风展开。
- 用户未提供参考素材时，本 Skill 虚拟出主体；用户提供参考素材时，建议改用全参考模式或 gaven 系列 Skill。
